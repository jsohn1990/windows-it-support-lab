# Microsoft 365 Password Reset — Help Desk Simulation

## Scenario

A simulated employee, Bob Smith, reported being unable to sign in to Microsoft 365 because he had forgotten his password.

## Environment

- Microsoft 365 admin center
- Microsoft Entra ID
- Cloud-only Microsoft 365 user account
- Jira Service Management

## Resolution

1. Located the user's account under **Users → Active users** in the Microsoft 365 admin center.
2. Selected **Reset password**.
3. Generated a temporary password.
4. Required the user to change the password at the next sign-in.
5. Signed in as the test user and completed the password change.
6. Verified that the account could successfully authenticate.

## Additional Account Administration

Practiced the following tasks using the same test account:

- Created a cloud-only Microsoft 365 user.
- Created a security group and added the user.
- Removed the user from the security group.
- Blocked the user's sign-in.
- Restored the user's sign-in access.

## Ticket Documentation

Created a simulated password-reset request in Jira Service Management, recorded the administrative actions and successful sign-in verification in an internal note, and marked the ticket resolved.

## Outcome

Completed a simulated Microsoft 365 account-recovery workflow and documented the resolution in a help desk ticket.

No passwords or authentication credentials are included in this documentation.
